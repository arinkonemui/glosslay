# Glosslay

**ゲーム画面翻訳ツール** — 日本語未対応のPCゲームをプレイしながら、
画面の外国語テキストをOCRで読み取り、翻訳してオーバーレイ表示する Windows アプリ。

`gloss`（言語学で、外国語の文に添える対訳注釈）+ `overlay` = **Glosslay**（グロスレイ）

- 配布予定: https://arinkolab.com/apps/glosslay/
- 対象OS: Windows 11
- 実装: C# / .NET 10 (LTS) + WPF

---

## 特徴（設計方針）

| | |
|---|---|
| **キー登録なしで動く** | ローカルNMTが既定。APIキーなしで全機能が使える。クラウド翻訳は任意のアップグレード |
| **ゲームを邪魔しない** | クリックスルー、フォーカスを奪わない、キー・パッド入力を消費しない |
| **アンチチートに安全** | DLLインジェクション・メモリ読み取りを一切行わない外部オーバーレイ方式 |
| **プライバシー** | 既定構成では画面テキストが一切外部送信されない |
| **数値を守る** | 原文と訳文の数値を照合。スキル説明のダメージ値・秒数の誤りを検出する |
